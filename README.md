## 📌 Project Overview

This project simulates a real-world enterprise analytics workflow :Transforming raw customer shopping data into actionable business intelligence. It demonstrates how organizations can leverage data analytics to understand customer behavior, improve retention strategies, optimize product performance, and support data-driven decision-making.

The project follows a **complete analytics lifecycle**: from data preparation and SQL-based business analysis to interactive Power BI dashboard development and executive-level stakeholder reporting.

> This solution reflects the type of analytical work commonly performed by **Data Analysts** and **Business Intelligence Analysts** across retail, e-commerce, consumer analytics, and marketing domains.

## 🔄 End-to-End Analytics Workflow

### 1️⃣ Data Preparation & Exploratory Analysis — Python

The raw customer shopping dataset was imported into Python for preprocessing and exploratory analysis.

**Key activities:**
- Data import and validation
- Missing value treatment & duplicate removal
- Data standardization and feature engineering
- Exploratory visual analysis (distributions, correlations, trends)

**Outcome:** A clean, analysis-ready dataset prepared for SQL and Power BI integration.

---

### 2️⃣ Business Analysis — SQL

The transformed dataset was loaded into a relational database to simulate enterprise-grade analytics workflows.

**Analytical areas covered:**

| Area | Description |
|---|---|
| Customer Segmentation | Identifying high-value and at-risk segments |
| Revenue Contribution | Analyzing which customers and products drive sales |
| Loyalty & Retention | Measuring repeat purchase rates and loyalty patterns |
| Purchase Behavior | Trend analysis across time, product, and category |
| Product Performance | Category-level revenue and frequency benchmarking |

**SQL concepts demonstrated:** Joins · CTEs · Aggregate Functions · Window Functions · Ranking Logic · Subqueries · Grouping & Filtering

---

## ⚙️ Project Setup & Execution

### Prerequisites
- Python 3.10+
- PostgreSQL, MySQL, or SQL Server
- Power BI Desktop
- Jupyter Notebook or VS Code

### Step 1 — Clone the Repository
```bash
git clone https://github.com/amlanmohanty1/customer-trends-data-analysis-SQL-Python-PowerBI.git
cd customer-trends-data-analysis-SQL-Python-PowerBI
```

### Step 2 — Run the Python Notebook
Open `notebooks/Customer_Shopping_Behavior_Analysis.ipynb` and run all cells. The notebook covers:
- Data import & cleaning
- Feature engineering
- Exploratory analysis
- SQL database connection and data load

### Step 3 — Execute SQL Queries
In your preferred database (PostgreSQL / MySQL / SQL Server):
1. Create a new database
2. Load the transformed data using the Python export scripts
3. Run `sql/customer_behavior_sql_queries.sql` to execute all business analyses

### Step 4 — Explore the Power BI Dashboard
1. Open `powerbi/customer_behavior_dashboard.pbix` in Power BI Desktop
2. Connect to your SQL database
3. Refresh the dataset and explore the interactive dashboard
